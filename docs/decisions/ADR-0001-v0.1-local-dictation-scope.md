# ADR-0001: Reframe 0.1 as local dictation

- Status: Accepted
- Date: 2026-08-19
- Owners: Product owner, Sol
- Supersedes: 2026-08-06 Assistant/Agent/Memory 0.1 documents

## Context

The earlier desktop repository described 0.1 as an Assistant with a reasoning API, memory, project state and recovery. Subsequent product review identified a smaller first-principles goal: reliably capture spoken ideas and make the resulting text immediately usable.

## Options

1. Continue the Assistant/Agent/Memory scope.
2. Keep the Assistant architecture but hide most features.
3. Reduce 0.1 to a complete local dictation loop and defer intelligence layers.

## Decision

Choose option 3. The only active 0.1 specification is `docs/specs/tsb-v0.1-design.md`.

0.1 contains local recording, VAD-stable segment transcription, SenseVoiceSmall, conservative cleanup, local retention, result UI and one clipboard delivery. It does not call an LLM. The API configuration screen only saves, cancels or deletes future 0.2 settings.

## Consequences

- The former Agent, memory, reasoning Provider and cloud-ASR plans are removed from the active tree.
- Git history remains the audit trail for those superseded documents.
- OpenDictation and Kaze are references, not product source trees.
- 0.2 may add bounded idea structuring after 0.1 produces real text-length and quality data.

## Verification

- The README, active spec, implementation plan and acceptance matrix all describe the same local-only 0.1 scope.
- A repository search finds no active 0.1 task that calls an LLM or implements memory/Agent behavior.

## Rollback

Restore branch `archive/pre-v0.1-reframe-20260818` or revert the repository-foundation commit. Do not combine both product scopes in one release.
