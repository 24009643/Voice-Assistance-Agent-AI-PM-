# TSB 0.2 Transcript Polish Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver traceable mixed Chinese-English transcript polish that waits at most 1.5 seconds after the durable local final, copies exactly once, and falls back locally without allowing organization or late Provider work to mutate delivery.

**Architecture:** Preserve Paraformer and SenseVoice as immutable candidates. Apply explicit local terminology, then run a separate strict text-only OpenAI-compatible polish request behind an exclusive MainActor delivery lease; organization starts afterward with the exact delivered text. Keep the current island layout unchanged and add only settings needed for independent polish authorization and terminology input.

**Tech Stack:** macOS 14+, Swift 6, SwiftUI, Foundation `URLSession`, CryptoKit, Security.framework Keychain, UserDefaults, XCTest, existing sherpa-onnx 1.13.6. No new package dependency.

**Spec:** `docs/superpowers/specs/2026-08-25-tsb-v0.2-transcript-polish-design.md`

- Auto-accept only formatting, submitted alias-to-canonical terminology, or another-candidate-supported edits. Context-only inference is review-only.
- The 1.5-second deadline starts after durable local save and is not a Stop-to-copy claim until target-Mac evidence exists.
- Exactly one automatic clipboard write per successful recording; late results and restart recovery never recopy.
- Reuse `URLSession`, the existing endpoint-bound secret, and atomic `TranscriptStore.save`; add no Provider SDK or storage abstraction.

- Automated tasks never access real microphone, recordings, login Keychain secrets, or a real Provider.

```swift
struct TranscriptTerminologyEntry: Equatable, Codable, Sendable {
    let canonical: String
    let aliases: [String]
}

struct TranscriptTerminologyEdit: Equatable, Codable, Sendable {
    let startUTF16: Int
    let lengthUTF16: Int
    let original: String
    let replacement: String
    let canonical: String
}

struct TranscriptTerminologyResult: Equatable, Sendable {
    let text: String
    let edits: [TranscriptTerminologyEdit]
}

enum TranscriptPolishState: String, Codable, Sendable {
    case notRequested, accepted, reviewRequired, timedOut, rejected, failed, cancelled
}

enum TranscriptDeliverySource: String, Codable, Sendable { case local, polished }

struct TranscriptCandidate: Equatable, Sendable {
    enum ID: String, Codable, Sendable { case offline, streaming }
    let id: ID
    let text: String
    let textSHA256: String

    init(id: ID, text: String)
}

enum TranscriptPolishEditKind: String, Codable, Sendable {
    case formatting, terminology, candidateSupported
}

struct TranscriptPolishEdit: Equatable, Codable, Sendable {
    let kind: TranscriptPolishEditKind
    let startUTF16: Int
    let lengthUTF16: Int
    let original: String
    let replacement: String
    let reason: String
}

enum TranscriptPolishOutcome: Equatable, Sendable {
    case accepted(baseCandidateID: TranscriptCandidate.ID, text: String, edits: [TranscriptPolishEdit])
    case reviewRequired(baseCandidateID: TranscriptCandidate.ID, text: String, edits: [TranscriptPolishEdit])
}

struct TranscriptPolishRecord: Equatable, Codable, Sendable {
    let requestID: UUID
    let state: TranscriptPolishState
    let baseCandidateID: TranscriptCandidate.ID?
    let polishedText: String?
    let reviewCandidateText: String?
    let edits: [TranscriptPolishEdit]
    let provider: String?
    let model: String?
    let providerKind: ProviderKind?
    let sentCharacterCount: Int?
    let elapsedMilliseconds: Int?
    let errorCode: String?
    let updatedAt: Date
}

struct TranscriptDeliveryReceipt: Equatable, Codable, Sendable {
    let source: TranscriptDeliverySource
    let stopToLocalFinalMilliseconds: Int
    let stopToCopyMilliseconds: Int
}
```
