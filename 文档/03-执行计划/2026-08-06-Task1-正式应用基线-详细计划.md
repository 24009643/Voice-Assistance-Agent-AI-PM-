# Task 1 正式 macOS 应用基线 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将固定版本的 OpenDictation 转化为独立、可重复构建、不会连接上游更新通道的 TSB macOS 正式应用基线，同时把 OpenDictation 和 Kaze 作为可追溯参考仓库登记在 `example`。

**Architecture:** `example/OpenDictation` 和 `example/Kaze` 使用 Git submodule 固定来源与 commit，只用于阅读和体验。正式产品是位于 `apps/macos/TSB` 的无嵌套 Git 快照 fork，拥有独立 bundle identifier、Keychain 命名空间、Application Support 目录、应用名称和构建入口；上游 Sparkle 更新能力在 0.1 基线中完全移除，避免 TSB 被 OpenDictation 更新包替换。

**Tech Stack:** Git submodule、macOS 14+、Swift 6、SwiftUI/AppKit、AVFoundation、Xcode 16+、XcodeGen、XCTest、Make。

## Global Constraints

- 正式工作目录固定为 `/Users/zhuohengchi/Desktop/The Second Brain`。
- OpenDictation 固定来源为 `https://github.com/kdcokenny/OpenDictation.git`，commit 为 `227c8b013ba4f4c7d8772b72f062354aae4443b1`。
- Kaze 固定来源为 `https://github.com/fayazara/Kaze.git`，commit 为 `98fd10adb6ddb641d97f2fa9c2a33a201523454c`。
- 正式应用目录固定为 `apps/macos/TSB`，不得直接在 `example` 中开发产品功能。
- 产品名固定为 `TSB`；Release bundle identifier 为 `com.zhuohengchi.tsb`；Dev bundle identifier 为 `com.zhuohengchi.tsb.dev`。
- 最低系统版本保持 macOS 14.0，Swift 保持 6.0，架构保持 arm64。
- Task 1 不替换 ASR、不增加记忆、不调用外部主模型 API，只建立可验证基线。
- 任何模型权重、构建产物、密钥、音频和运行数据库不得进入父仓库提交。
- 所有变更遵守 `文档/03-执行计划/工程执行标准.md`。
