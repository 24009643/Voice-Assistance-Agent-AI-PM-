# TSB 0.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付一个可在 macOS 上完成听写、稳定转录、个性化总结、本地记忆落地和重启恢复的 TSB 0.1。

**Architecture:** 以 OpenDictation 的录音、快捷键和轻量界面作为参考基座，在正式应用目录建立 TSB fork。系统使用一个 SecondBrain Agent 和确定性的 SessionOrchestrator；本地负责录音、国产 ASR、持久化和检索，一个国产主模型 API 负责语义修正、总结和结构化提取。

**Tech Stack:** macOS 14+、Swift 6、SwiftUI/AppKit、AVFoundation、Swift Concurrency、XcodeGen、XCTest、SQLite/GRDB、macOS Keychain、国产本地 ASR、国产主模型流式 API。

## Global Constraints

- 0.1 只交付“听写 → 稳定转录 → 个性化总结 → 记忆落地 → 下次恢复”。
- 只有一个 SecondBrain Agent；SessionOrchestrator 是确定性代码。
- 正常记录流程只依赖一个外部国产主模型 API。
- 不实现 TTS、Barge-in、多 Agent、第三方自动操作或全盘扫描。
- API Key 只进入 Keychain，用户正文不得进入普通日志。
- 稳定派生数据事务写入成功后才删除音频；失败音频保留 24 小时且总量不超过 2GB。
- `main` 必须始终可构建；每个任务必须独立测试、独立审查、独立提交。
- 详细代码任务开始前，必须从本总计划拆出对应组件计划并通过评审；不得跨越阶段门禁并行修改同一状态所有权。
