# The Second Brain

The Second Brain（TSB）是一个以无感语音记录、个性化整理和长期记忆为起点的 macOS 个人 Assistant。

## 当前阶段

当前版本：`0.1` 设计与执行准备阶段。

0.1 只完成以下闭环：

> 听写 → 稳定转录 → 个性化总结 → 记忆落地 → 下次恢复
